# Taller de Git y GitHub · 2º ASIR

Programa colaborativo: cada miembro de la clase añade su propio saludo
en la carpeta `alumnos/`.

## Cómo ejecutarlo

```bash
python3 main.py
```

## Cómo añadir tu saludo

1. Crea el fichero `alumnos/nombre_apellido.py` (minúsculas, sin tildes ni guiones).
2. Define dentro una función `saludar()` que haga un `print`.
3. Comprueba que funciona con `python3 main.py`.
